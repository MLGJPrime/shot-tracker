# 🏀 Basketball Shot Tracker

A clean and interactive web-based shot tracking tool for basketball training.

## 🚀 Features

- Dynamic shot entry table (type, zone, made/attempted)
- Fully accurate SVG halfcourt based on NBA dimensions
- Interactive shot zones ready for color-coded FG% feedback
- Tailwind CSS styling for modern UI
- Easy to extend with history logging, charts, or database storage

## 📦 Technologies

- HTML5 / CSS3
- JavaScript (Vanilla)
- TailwindCSS
- SVG graphics (for the court)
